# Task Preparation

Before attempting the task, produce a short preparation checklist covering:

1. **Missing information** — context that would materially change the approach if known
2. **Hidden assumptions** — things that would otherwise be assumed silently; state them explicitly
3. **Sub-problems** — how the task breaks down into components
4. **Pitfalls** — edge cases, ambiguities, or ways the task could be misread
5. **Tools/resources needed** — and whether they're actually available

Keep each point concrete and specific to the task at hand — generic boilerplate ("consider the requirements") defeats the purpose.
